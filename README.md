# Employee Performance Mapping – SQL Project

A SQL-based employee performance analysis project built around an `employee` database and `emp_record_table`.

## Project Overview

This project demonstrates practical SQL analysis for employee data, including:

- Employee and department details
- Employee performance rating analysis
- Leadership-role identification
- Maximum performance rating by department
- Minimum and maximum salary by role
- Experience ranking
- Salary-based views
- Country-wise salary analysis
- Index creation and query analysis using `EXPLAIN`
- Average salary by continent and country
- Highest-salary employee identification
- Training/review candidate identification
- Distinct job-role analysis

## SQL Topics Demonstrated

- `SELECT`, `WHERE`, `BETWEEN`, `LIKE`
- `GROUP BY`, aggregate functions (`MIN`, `MAX`, `AVG`)
- Window functions: `RANK()` and `MAX() OVER (PARTITION BY ...)`
- Subqueries
- Views
- Indexes
- `EXPLAIN`
- Sorting and filtering
- Database/table inspection

## Database

The SQL scripts create and use the `employee` database and work with the `emp_record_table`.

## Project Files

The repository contains the SQL scripts, project report/documentation, database/Excel resources, screenshots, submission documents, and the original project package.

### SQL Scripts

The numbered SQL scripts cover database setup and the individual analysis tasks. `Employee_Performance_Mapping_Master.sql` contains the consolidated SQL solution.

## How to Use

1. Open a MySQL-compatible SQL environment.
2. Run `01_database_setup.sql` to create/use the database.
3. Run the remaining numbered SQL scripts in sequence as required.
4. Review `Employee_Performance_Mapping_Master.sql` for the consolidated solution.
5. Refer to the report and screenshots for project documentation and results.
